# Hype GIF-ovi

Ubaci ovdje GIF-ove koji se prikazuju nakon spremljenog treninga.

- Podržano: `.gif`, `.webp`, `.png`, `.jpg`, `.mp4`, `.webm`
- Imena datoteka su nebitna — Vite ih pokupi globom pri buildu
- Bilo koji broj datoteka; prikazuje se nasumična
- Ako je mapa prazna, prikaže se emoji odabranog tipa treninga

Kvadratni format (1:1) izgleda najbolje jer se medij renderira u kvadratnom okviru.
